REST API for an online classified ads platform built with Node.js, Express, and MongoDB. Includes OTP authentication, role-based access, hierarchical categories, dynamic options, image upload, pagination, and Swagger docs.

بک‌اند پلتفرم آگهی آنلاین با Node.js، Express و MongoDB. شامل ورود با OTP، کنترل دسترسی بر اساس نقش، دسته‌بندی درختی، گزینه‌های پویا، آپلود تصویر، صفحه‌بندی و مستندات Swagger.
